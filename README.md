## ✨ Features

- 🎯 **Domain-Specific Categorization**:
  - 📐 **Quantitative Aptitude** (*Time & Work, Speed-Distance, Profit & Loss, P&C, Probability, Ratios, Ages*)
  - 🧩 **Logical Reasoning** (*Blood Relations, Coding-Decoding, Syllogisms, Number Series, Seating Arrangements*)
  - 📚 **Verbal Ability & English** (*Sentence Correction, Spotting Errors, Synonyms/Antonyms, Grammar rules*)
  - 💻 **Data Structures & Algorithms (DSA)** (*Binary Trees, QuickSort Worst-Case, Monotonic Stacks, Dijkstra, Kadane's, Floyd's Cycle*)
  - ⚙️ **Core Computer Science** (*Deadlocks/Coffman Conditions, ACID Properties, OSI Layers, SQL 2NF Normalization, Thrashing, B+ Trees*)
  - 🌐 **Web Dev & Programming** (*JavaScript Event Loop, Closures, React Virtual DOM, CORS, HTTP Status Codes*)
  - 🚀 **Full Placement Mock Test (Mixed)** (*Simulating TCS NQT, Infosys DSE, and AMCAT assessment rounds*)

- 🔀 **100% Dynamic Randomization**:
  - Questions and all 4 options (A, B, C, D) are shuffled dynamically with the **Fisher-Yates algorithm** on every attempt.

- 🏷️ **Authentic Interview Metadata**:
  - Questions tagged with real hiring companies: `[TCS NQT]`, `[Infosys DSE]`, `[Amazon]`, `[Accenture]`, `[Wipro]`, `[Google]`, `[Microsoft]`, `[Cognizant]`.
  - Step-by-step conceptual & mathematical solutions for every problem.

- ⚡ **Interactive Exam Utilities**:
  - ⏱️ **Live Countdown Timer** with low-time warning pulsation.
  - 💡 **50:50 Lifeline** to eliminate 2 incorrect choices.
  - 🚩 **Mark for Review / Flagging** functionality.
  - 📋 **Collapsible Question Matrix / Palette Drawer** with status indicators (Answered, Marked, Unvisited).
  - 🔊 **Zero-Asset Web Audio Engine** for responsive sound feedback.
  - 🎉 **Canvas Confetti Celebration** on achieving high scores (>= 70%).
  - 🌓 **Dark & Light Mode** with local storage persistence.
